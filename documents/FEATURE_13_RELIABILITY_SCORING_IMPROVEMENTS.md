# Feature 13 — Reliability Scoring Improvements

## Overview

Feature 13 replaces the earlier fixed-penalty calculation with a context-aware reliability scoring model. The improved engine produces more meaningful scores by considering the seriousness, reach, confidence, source, and lifecycle state of every active issue.

The resulting score is used consistently across audits, dataset health, summaries, reports, remediation outcomes, and historical comparisons.

## Weighted Quality Dimensions

The overall reliability score is calculated from five weighted dimensions:

- Completeness
- Validity
- Consistency
- Uniqueness
- Reliability

Dimension weights are normalized before calculation, making the model configurable while ensuring the final score remains on a 0–100 scale.

## Severity and Affected-Row Impact

Each finding contributes a deduction based on:

- Issue severity
- Percentage of affected records
- Detection confidence
- Dataset criticality
- Whether the issue was generated by a reusable quality rule

The affected-row calculation uses a progressive breadth factor. Small defects still receive attention, while widespread failures receive materially larger deductions without allowing one issue to distort the entire score unrealistically.

## Dataset Criticality

Scoring supports four dataset-criticality levels:

- Low
- Medium
- High
- Mission critical

Higher-criticality datasets receive stronger deductions for the same issue because failures have greater operational or business impact.

The scoring context can be changed and the audit recalculated without rerunning the full dataset audit.

## Issue Lifecycle Awareness

The scoring engine now responds to issue workflow state:

- Open issues receive their full calculated deduction.
- In-progress issues retain most of their deduction until validation confirms a fix.
- Accepted risks receive a configurable discounted deduction.
- Fixed and ignored issues no longer reduce the score.

Changing an issue status or applying a recommendation immediately recalculates the audit score, summary, dataset health, and active issue count.

## Rule Importance

Issues generated by assigned reusable quality rules receive a configurable multiplier.

This gives governed business rules greater influence than general heuristic findings and helps teams reflect explicitly defined reliability expectations in the final score.

## Explainable Score Breakdown

Every score contains an explainable breakdown including:

- Dimension scores
- Normalized dimension weights
- Dataset criticality
- Active issue count
- Accepted-risk count
- Total weighted penalty
- Per-issue deductions
- Human-readable deduction reasons

Deductions are ordered by impact so users and downstream services can identify the findings contributing most to reliability loss.

## Score Recalculation

A saved audit can be recalculated using a different scoring context without rerunning ingestion or profiling.

Supported adjustments include:

- Dataset criticality
- Accepted-risk discount
- Rule-issue multiplier

The recalculated score and summary are persisted and reflected in the Dataset Registry.

## API Support

Feature 13 adds the following endpoints:

```text
GET  /audits/{audit_id}/score-breakdown
POST /audits/{audit_id}/score/recalculate
```

The score-breakdown endpoint returns the complete scoring context, dimension results, and highest-impact deductions.

The recalculation endpoint updates the scoring context, recalculates the score, regenerates the audit summary, and updates the related dataset record.

## Reporting and Audit Consistency

Resolved and ignored issues no longer inflate:

- Dataset issue counts
- Audit risk summaries
- Executive reports
- Recommended focus areas

Historical issues remain stored for traceability, while active reliability reporting reflects the current issue state.

## Security and Workspace Isolation

Score-breakdown and recalculation operations require authentication and remain scoped to the active workspace. A user cannot inspect or recalculate an audit belonging to another workspace.

## Foundation for Future Features

Feature 13 provides the scoring foundation for:

- Issue Lifecycle Management
- Dataset criticality controls
- Reliability score configuration
- Service-level objectives
- Risk acceptance governance
- Remediation impact forecasting
- Reliability trends and executive dashboards
