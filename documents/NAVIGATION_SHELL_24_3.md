# Navigation Shell 24.3

## Overview
Refines the desktop sidebar into a clean expandable navigation rail while preserving the mobile off-canvas menu.

## Changes
- Removed the desktop header hamburger control.
- Kept the bottom Collapse/Expand control as the only desktop sidebar toggle.
- The collapsed sidebar displays only the Expand arrow and does not expose hover flyouts.
- Removed filled backgrounds from navigation group headings.
- Reduced collapsed rail width and eliminated group spacing in the collapsed state.
- Constrained the workspace selector and add-workspace control to prevent horizontal overflow.
- Preserved the sticky DRC product header in the expanded sidebar.

## Responsive behavior
Mobile navigation continues to use the top-bar off-canvas menu. Desktop collapse preferences remain stored locally.
