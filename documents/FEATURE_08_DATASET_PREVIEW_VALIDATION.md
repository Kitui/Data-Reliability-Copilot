# Feature 08 — Dataset Preview and Validation

Feature 08 strengthens dataset onboarding and inspection. CSV uploads are validated before processing, with clear failures for unsupported, empty, malformed, oversized, or structurally invalid files. Imported datasets expose an accurate, scrollable schema profile showing inferred types, missing values, uniqueness, and safe example values.

The Dataset Registry uses neutral rows, supports live refresh, and provides editable labels for dataset classification. Recommended actions open the selected dataset directly in the Audit Workspace so reliability work can continue without duplicate navigation controls.


The interface uses cache-versioned assets and isolated component styles so dataset rows, recommendations, and labels retain their intended neutral presentation.
